# BRAND.md adapter boundary

Company.md does not select a single BRAND.md dialect. When a repository already contains one:

- map brand strategy and positioning to `COMPANY.md` only when an accountable owner approves the mapping;
- map verbal behavior to `VOICE.md`;
- link an existing compatible visual system through `DESIGN.md` rather than copying tokens;
- preserve the original BRAND.md and record its dialect or schema in the adoption report;
- surface conflicts instead of choosing a source automatically.
