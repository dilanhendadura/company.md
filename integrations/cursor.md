# Cursor adapter

Install `companymd install . --agent cursor` in the project. Cursor discovers the portable skill at `.agents/skills/company/SKILL.md`; an existing Codex or Copilot installation in that directory already supplies it.

For company or product work, use that skill to resolve the requested subject, generate one validated context, and follow explicit design/template bindings. Keep business facts in the source pack and preserve existing Cursor rules. This installation provides the skill and runner; host discovery and artifact behavior still need validation in the actual Cursor version used by the team.
